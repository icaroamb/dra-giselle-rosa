Proposta de layout para a Dra. Giselle Rosa, biomédica esteta (Goiânia, Anápolis e São Paulo) e Instituto GR.
**Não é o site oficial.**

- Página estática: `index.html` (HTML, CSS e um script curto, sem dependências) + imagens em `assets/`
- Dois públicos: pacientes (tratamentos e unidades) e profissionais (cursos, mentoria e grupo do Instituto GR)
- A página tem `noindex, nofollow` para não aparecer nas buscas
